# 聊天起始页 0.3.3

适用于 SillyTavern 1.18.0。保留原生首页，默认隐藏最近聊天；进入角色卡时先询问是否新建聊天。隐藏入口改为按本地日期计算的四位数字，不需要输入框，也不需要 Option、Alt 等组合键。

0.3.3 修复启动时闪过「开始新的对话」占位卡片：原生首页尚未就绪时，只保留中间区域的背景；首页就绪后直接进入原生首页。加载角色时，角色数据就绪后才显示对应的新建询问。其他扩展在主聊天区域之外发出的通知不受此修复影响。

## 用当天日期打开

先点一下首页或「是否新建一个聊天？」卡片的空白处，让光标离开聊天框、搜索框等输入区域。然后直接在键盘上连续按当天的四位日期，不需要回车。

| 日期示例 | 依次按键 |
| --- | --- |
| 10 月 18 日 | 1018 |
| 10 月 19 日 | 1019 |
| 1 月 2 日 | 0102 |
| 12 月 31 日 | 1231 |

规则是两位月份加两位日期（MMDD），不足两位补 0。使用电脑上浏览器的本地日期，跨天后自动更新，不用刷新。

- 首页：展开原生最近聊天列表，可以直接点击某条记录进入。
- 角色卡的询问页：打开该角色原生聊天管理列表，可以搜索和选择更早的记录，包括新建之前的上一段。
- 页面不显示数字、输入框、提示或输入进度。
- 相邻按键停顿超过 3 秒、按其他键、点击页面、按 Esc、切换角色或切走标签页，会清空未完成的数字。
- 在聊天框、搜索框、可编辑区域中输入日期，只保留普通输入行为，不会打开记录。
- 已经展开聊天正文时，不截取数字按键。需要查看别的记录时，先按 Esc 收起，再按当天日期。
- 正在生成时也能打开历史列表；可选择当前记录继续查看。真正切换到其他记录或新建聊天，仍需先停止生成。

0.3.2 已关闭旧的标题长按、Option/Alt 加长按、首页版本号或 Logo 长按入口。点击或三连点标题不会展开记录。

按 Esc 收起时不再把焦点移到询问标题上，避免标题出现蓝色焦点边框；同时清理历史搜索框的焦点，避免数字被输入到已经隐藏的搜索框。

Mac、Windows、Linux 都使用同一套数字操作。有实体键盘的小键盘也可以输入；请开启 Num Lock。本版不为触屏设备额外显示数字键盘。

## 首页

保留酒馆原来的版本号、链接、欢迎内容与三个快捷按钮，只把最近聊天列表、预览和明显的展开按钮默认隐藏。

按当天日期展开后，点击某一条就打开那一条聊天，不必先进入角色卡。加载期间，角色卡其他聊天的正文保持遮挡。

点击列表上方关闭图标、按 Esc 或切换浏览器标签页可以重新隐藏。刷新或返回首页后也默认隐藏。展开状态不会写入账号设置，也不改变酒馆原来的最近聊天隐藏偏好。

首页显示的数量仍由原生最近聊天设置决定，保留原生「显示更多」和设置功能。需要某个角色更早的全部记录时，进入该角色的询问页，再按日期打开聊天管理。

## 角色卡

进入角色卡时，先显示「是否新建一个聊天？」，只提供「新建聊天」和「返回首页」。

- 「新建聊天」：使用酒馆原生功能创建独立的新聊天，保留原对话。
- 「返回首页」：关闭当前角色，显示原生首页，最近聊天默认隐藏。
- 右上角「起始页」或 Esc：收起当前对话。
- 按当天日期：打开聊天管理。选择哪一条，就进入哪一条，支持搜索、重命名和导出等原生功能。
- 如果输入框有未发送内容，切换到另一条记录或新建会暂时阻止；选择当前记录进入后先处理草稿。

之前版本创建的聊天仍可在原生聊天管理中选择；按日期本身不会新建聊天。新版继续保留 0.3.1 对首页三个快捷按钮的兼容修复。

## 安装和更新

已有 st-chat-privacy 时，覆盖同一个文件夹后刷新即可，不要同时启用两个副本。

### Mac 覆盖安装

下载 ZIP 到「下载」文件夹，在终端执行：

~~~bash
unzip -o "$HOME/Downloads/SillyTavern-Chat-Privacy-0.3.3.zip" \
  -d "$HOME/Desktop/SillyTavern/public/scripts/extensions/third-party"
~~~

看到四个文件的解压输出后，回酒馆网页按 Command + Shift + R 强制刷新。扩展名称仍是「聊天起始页」，版本为 0.3.3。

### 从 Git 仓库安装

把扩展仓库链接粘贴到酒馆的「扩展 → 安装扩展」。仓库根目录需要直接包含 manifest.json、index.js、style.css 和 README.md。手动解压安装时，则把整个 st-chat-privacy 文件夹放入酒馆的第三方扩展目录。

## 验证

1. 首页默认看不到最近聊天列表；按当天日期后可以展开。
2. 在聊天框或搜索框里输入同样的数字，不会展开记录。
3. 进入角色卡，仍先看到新建询问；按当天日期后能选择多段历史。
4. 新建后，原记录和新记录都存在，仍可从聊天管理分别打开。
5. 按 Esc 或切换标签页后，正文与聊天管理重新隐藏。
6. 首页的 API 连接、角色管理、扩展程序三个按钮仍能打开对应面板。

针对官方 SillyTavern 1.18.0、提交 51ad27fb8，使用原生 HTML、首页模板和选定的原生函数，在模拟 DOM 与模拟后端中通过 81 项当前版本检查。覆盖每日日期计算、跨日与跨年、前导 0、错误和超时清空、输入框隔离、旧手势关闭、完整历史入口、独立新建、保留文件、生成中的只读访问、切换过程的遮挡、Esc 后的焦点处理，以及原生首页加载前的占位卡片隐藏。

这些检查不等同于完整浏览器或实际酒馆实例测试，主题和其他扩展仍可能影响表现。

## 数据与范围

日期数字仅在页面内存中短暂匹配，不写入账号设置，也不发送给模型。插件沿用酒馆原生聊天功能，不增加外部服务。

本扩展提供界面隐藏，不提供密码验证或聊天文件加密。日期规则是可预测的，知道规则的人也能展开。角色头像、角色编辑面板、浏览器标题和其他扩展弹窗不在遮挡范围内。

隐藏、展开和输入日期不会自动删除聊天。原生聊天管理中的删除功能仍由你自行操作。Esc 不会停止已开始的模型生成。旧记录改名或删除后，可在原生聊天管理中寻找现有文件。

## 卸载

在扩展管理中禁用「聊天起始页」并刷新，或移走 st-chat-privacy 文件夹后刷新。已有聊天仍由酒馆保留。
