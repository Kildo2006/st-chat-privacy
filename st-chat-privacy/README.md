# 聊天起始页 0.3.1

适用于 SillyTavern 1.18.0。首页和角色卡分别处理：首页保留原生布局，只收起「最近聊天」；进入角色卡仍先询问是否新建聊天。

0.3.1 增加首页快捷按钮兼容修复：当欢迎消息重新渲染后，恢复「API 连接、角色管理、扩展程序」三个原生按钮的样式和入口。修复只作用于原生系统欢迎消息中的这三个按钮。

## 首页：单独隐藏最近聊天

- 不选角色时，显示酒馆原来的首页、版本号、链接和欢迎内容，不再用大卡片占满首页。
- 「最近聊天」列表、预览和原来的明显展开按钮默认隐藏。
- 用鼠标左键或触控板按住首页版本号 2 秒，显示原生最近聊天列表。长按左侧酒馆 Logo 也可以。
- 展开后直接点击某一条，就打开那一条聊天，不必先进入角色卡。加载过程中，角色卡的其他聊天正文保持遮挡。
- 再长按版本号、点击列表上方的关闭图标、按 Esc 或切换浏览器标签页，都可以重新收起列表。
- 刷新或返回首页后默认重新隐藏。展开状态不写入账号设置，也不改变酒馆原有的最近聊天隐藏偏好。

首页保留原生「显示更多」和最近聊天设置。首页显示多少条仍由酒馆原来的最近聊天数量设置决定；需要更早的全部记录时，可使用下面的角色聊天管理入口。

## 角色卡：新建、恢复与全部历史

进入角色卡时，先显示「是否新建一个聊天？」，只提供「新建聊天」和「返回首页」。

| 操作 | 结果 |
| --- | --- |
| 点击「新建聊天」 | 使用酒馆原生功能创建一段独立新聊天，保留原对话 |
| 普通长按询问标题 2 秒 | 恢复该卡的上一段聊天，沿用 0.2.0 的方式 |
| 按住 Mac 的 Option（⌥）键，再长按询问标题 2 秒 | 打开该卡原生聊天管理列表，可搜索和选择任意一段现有聊天 |
| 点击「返回首页」 | 关闭当前角色，显示原生首页，最近聊天默认隐藏 |
| 点击右上角「起始页」或按 Esc | 收起当前对话 |

Windows/Linux 用 Alt 代替 Option。页面本身不显示这些隐藏操作的提示。

从未通过本扩展新建过时，普通长按会展开该卡当前已有的聊天。通过本扩展新建后，重新点击同一张角色卡，再普通长按，会回到最近一次新建之前的那段对话。每张角色卡分别保存自己的前一段入口，兼容 0.2.0 保存的入口。

Esc 或切换标签页只是暂时收起正在查看的对话；回来后普通长按会恢复刚才那段。如果要回到新建之前的上一段，请先重新点击同一张角色卡。

聊天管理中的搜索、重命名、导出等功能继续使用酒馆原生界面。选择记录后直接进入选中的那一段；不再只限于上一段。按 Esc、切换角色或切到其他浏览器标签页时，聊天管理列表也会收起。

如果输入框有未发送内容，切换或新建会暂时阻止。先普通长按进入当前聊天，处理草稿后再操作。本扩展不会替你丢弃草稿。

## Mac 覆盖安装

下载新版 ZIP 到「下载」文件夹，在终端执行：

~~~bash
unzip -o "$HOME/Downloads/SillyTavern-Chat-Privacy-0.3.1.zip" \
  -d "$HOME/Desktop/SillyTavern/public/scripts/extensions/third-party"
~~~

然后回到酒馆网页，按 Command + Shift + R 强制刷新。扩展名称仍为「聊天起始页」，版本为 0.3.1。

覆盖同一个 st-chat-privacy 文件夹即可。不要将新旧版本分别放在两个目录中同时启用。

## 验证

1. 回到不选角色的首页，确认恢复原生布局且最近聊天隐藏。
2. 长按首页版本号 2 秒，确认最近聊天出现，点击一条较早的记录，确认打开的是所选记录。
3. 进入一张角色卡，确认仍先出现新建询问。
4. 按住 Option，再长按询问标题 2 秒，确认能选择该卡更早的聊天。
5. 按 Esc 或切换浏览器标签页，确认正文和聊天管理列表重新收起。
6. 在首页依次点击「API 连接、角色管理、扩展程序」，确认各自能打开对应面板。

针对官方 SillyTavern 1.18.0、提交 51ad27fb8，使用原生 HTML、首页模板、相关样式和选定的原生功能，在模拟 DOM 与模拟后端中通过 110 项检查，包括独立新建、保留前后两段、首页单独隐藏、指定历史的打开、完整聊天管理入口、切换过程的遮挡、草稿保留及后台完成不展开。新增检查使用原生欢迎按钮模板和面板点击函数，确认三个按钮各自打开对应面板，消息重新渲染后能再次修复，而且普通聊天不能因此获得原生界面操作入口。

上述检查不等同于完整浏览器或实际酒馆实例测试，主题和其他扩展仍可能影响表现。

## 数据与范围

本扩展使用本机酒馆的原生功能，不连接新增第三方服务，不主动请求模型生成。上一段聊天的角色标识和文件引用保存在账号设置中，不复制聊天正文。不会因为进入角色卡、隐藏或展开而自动新建或删除聊天。

它提供界面隐藏，不提供密码验证或聊天文件加密。角色头像、角色编辑面板、浏览器标题和其他扩展弹窗不在遮挡范围内。知道隐藏操作的人也可以展开内容。

新建与恢复沿用酒馆原有保存机制；原生聊天管理中的删除功能仍由你自行操作。Esc 不会停止已经开始的模型生成。重命名或删除历史文件后，如果旧入口失效，可使用原生聊天管理寻找现有记录。

## 卸载

在扩展管理中禁用「聊天起始页」后刷新，或移走 st-chat-privacy 文件夹后刷新。已有聊天仍由酒馆保留。
