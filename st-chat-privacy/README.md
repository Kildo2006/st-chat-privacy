# 聊天起始页 · SillyTavern Chat Privacy

保留 SillyTavern 原生首页和聊天管理，默认隐藏聊天记录。打开角色卡时先显示「是否新建一个聊天？」，需要查看历史时，直接按当天日期的四位数字。

**当前版本：0.3.6** · 适配基线：SillyTavern 1.18.0 · 支持使用实体键盘的 macOS、Windows 和 Linux 浏览器。

> 这是界面隐藏工具，不是密码锁或聊天文件加密工具。知道日期规则的人也可以打开记录。

## 主要功能

- 保留原生欢迎页、版本信息和快捷按钮，默认隐藏「最近聊天」及其预览。
- 进入角色卡或群聊时先显示新建询问，避免直接展示上一次的聊天正文。
- 使用当天日期打开原生历史管理，可以搜索并选择更早的记录。
- 使用酒馆原生功能新建聊天，保留已有角色与群聊记录。
- 支持原生临时聊天，以及临时聊天的隐藏、恢复、加载和导出操作。
- 切换浏览器标签页后恢复原来的聊天或列表；按 Esc 或点击「起始页」可以手动隐藏。
- 不增加输入框、数字键盘或页面上的解锁提示，不需要 Option／Alt 等组合键。

## 安装

先确认酒馆能够正常启动。安装或更新扩展时，不需要修改酒馆的聊天数据目录。

### 方式一：手动安装 ZIP

解压发布的 `SillyTavern-Chat-Privacy-0.3.6.zip`，把其中的整个 `st-chat-privacy` 文件夹放到：

```text
SillyTavern/
  public/scripts/extensions/third-party/
    st-chat-privacy/
      manifest.json
      index.js
      style.css
      README.md
```

不要把 ZIP 本身放进扩展目录，也不要套成两层 `st-chat-privacy/st-chat-privacy/`。

**Mac 命令行示例**

如果酒馆位于桌面的 `SillyTavern` 文件夹，ZIP 已下载到「下载」文件夹，复制下面整条命令到终端执行：

```bash
unzip -o "$HOME/Downloads/SillyTavern-Chat-Privacy-0.3.6.zip" \
  -d "$HOME/Desktop/SillyTavern/public/scripts/extensions/third-party"
```

看到 `README.md`、`index.js`、`manifest.json`、`style.css` 四个文件的解压输出后，回到酒馆网页强制刷新：

| 系统 | 刷新快捷键 |
| --- | --- |
| macOS 的 Chrome／Firefox | `Command + Shift + R` |
| Windows／Linux 的 Chrome／Firefox | `Ctrl + Shift + R` |

如果酒馆装在其他位置，请把命令里的目标路径改成自己的安装路径。

### 方式二：从 GitHub 仓库安装

如果扩展已经上传到 GitHub：

1. 在酒馆打开「扩展」面板，选择「安装扩展」。
2. 粘贴扩展的 GitHub **仓库链接**，完成安装。
3. 刷新酒馆网页，在扩展列表中确认「聊天起始页」已启用。

供发布者使用的仓库结构：`manifest.json`、`index.js`、`style.css`、`README.md` 应直接放在**仓库根目录**。只上传 ZIP，或在仓库里再套一层文件夹，无法按上述方式安装。

仓库只需要这四个扩展文件。不要上传酒馆的聊天记录、账号数据或 API 密钥。

### 首次使用

- 在扩展列表中确认版本为 **0.3.6**，并且只有一份「聊天起始页」启用。
- 如果希望每次启动都进入原生首页，请在酒馆用户设置中关闭 **Auto-load Last Chat（自动加载上次聊天）**。扩展不会替你更改此设置。
- 打开一张角色卡，确认先出现新建询问，再按下面的方法查看历史。

## 用当天日期打开记录

先点击页面空白处，让光标离开聊天框、搜索框等输入区域。然后连续按四个数字，**不需要回车**。

规则是 **两位月份 + 两位日期（MMDD）**，不足两位补 `0`：

| 电脑上的本地日期 | 依次按键 |
| --- | --- |
| 10 月 18 日 | `1018` |
| 10 月 19 日 | `1019` |
| 1 月 2 日 | `0102` |
| 12 月 31 日 | `1231` |

使用浏览器所在设备的本地日期。跨天后自动采用新日期，不需要重新设置或刷新。

| 当前页面 | 按完当天日期后 |
| --- | --- |
| 原生首页 | 展开原生「最近聊天」，点击某条记录即可打开 |
| 角色卡的新建询问页 | 打开该角色的完整原生聊天管理列表 |
| 群聊的新建询问页 | 打开该群聊的原生聊天管理列表 |
| 已手动隐藏的临时聊天 | 恢复当前页面中同一段临时聊天 |

输入时请留意：

- 相邻数字之间不要停顿超过 **3 秒**。输入错了，可以稍等后重新输入完整四位数。
- 点击页面、按其他键、按 Esc、切换角色或切走标签页，会清空未完成的数字。
- 输入框、搜索框和可编辑区域中的数字保持普通输入行为，不会解锁记录。
- 已经显示聊天正文时，扩展不会截取数字。想查看其他历史，可以先按 Esc 收起，再按日期。
- 不要按住 Ctrl、Command 或 Alt／Option。数字小键盘需要开启 Num Lock。
- 页面不会显示输入进度或成功提示，正确输入后直接展开相应内容。

旧版的标题长按、Option／Alt 加长按、首页版本号或 Logo 长按入口均已关闭；点击或三连点标题也不会打开历史。

## 首页、角色卡与群聊

### 首页的最近聊天

首页外观沿用酒馆原来的欢迎页。最近聊天的列表、预览和明显的展开按钮默认隐藏。

按日期后，可直接点击列表中的某一条进入那段聊天。列表显示数量仍由原生设置控制，原来的设置和「显示更多」功能继续可用。要查某个角色更早的全部记录，请进入角色卡，再按日期打开聊天管理。

点击原生列表的关闭图标或按 Esc，会重新隐藏最近聊天。返回首页或刷新后也默认隐藏。只切换浏览器标签页时，切回来会恢复列表原来的展开状态。

### 角色卡和群聊的询问页

| 操作 | 结果 |
| --- | --- |
| 点击「新建聊天」 | 创建独立的新聊天，保留原有角色／群聊记录 |
| 点击「返回首页」 | 关闭当前聊天，回到原生欢迎页 |
| 按当天日期 | 打开当前角色／群聊的历史管理，可搜索、选择、重命名或导出 |
| 在正文页面点击「起始页」或按 Esc | 收起正文，回到新建询问页 |

「起始页」按钮表示**收起当前聊天**；要回到原生欢迎页，请在询问页点击「返回首页」。从历史列表选择记录不会自动新建聊天。

如果输入框中还有未发送的内容，扩展会阻止新建或切换到其他记录。先重新打开当前记录，处理草稿，再继续操作。

正在生成回复时，可以打开历史列表或重新查看当前记录；切换到另一条记录、新建聊天或返回首页前，需要先停止生成。Esc 只隐藏界面，不会停止生成。

## 切换标签页、隐藏与刷新

**0.3.6 起，切回酒馆标签页会恢复离开前的界面，不再因切换标签页而停留在新建询问页。**这一行为适用于角色聊天、群聊、临时聊天，以及已经展开的首页最近聊天和历史管理列表。

| 切走前的状态 | 切回后的状态 |
| --- | --- |
| 正在查看聊天正文 | 继续显示同一段聊天，保留未发送草稿 |
| 历史管理列表已打开 | 恢复列表，保留搜索框内的文字 |
| 首页最近聊天已展开 | 恢复展开状态 |
| 已按 Esc 或点击「起始页」手动隐藏 | 保持隐藏，仍需按当天日期打开 |

后台标签页中的聊天与列表会暂时遮挡，但不会清除已打开的状态。切换标签页不会新建聊天、重新加载聊天文件或清空草稿；未输入完整的日期数字仍会清空。

刷新、关闭或真正离开酒馆网页，以及切换到另一张角色卡，仍沿用默认隐藏行为。后台完成的一次新建或历史加载不会因此自动获得显示权限；可以按日期重新打开。

## 临时聊天

在原生首页点击「临时聊天」，即可使用酒馆原生的临时会话。「起始页」按钮位于独立的一行，不再悬浮压住原生「加载／保存」按钮。

### 手动隐藏与恢复

1. 按 Esc 或点击「起始页」，收起临时聊天。
2. 点击空白处，按当天日期，恢复同一段临时聊天。
3. 要回到欢迎页，在询问页点击「返回首页」。要换一段临时会话，点击「新建聊天」。

有未发送草稿时，扩展会阻止新建或返回首页。先按日期恢复临时聊天，处理草稿后再操作。

### 临时聊天怎样保留

临时聊天使用酒馆原来的临时会话规则，**不会自动加入角色卡的历史记录**。需要保留时，请用原生「保存」按钮导出 JSONL 文件；「加载」用于导入文件。

切换浏览器标签页和手动隐藏只改变显示状态。返回首页、切换到角色卡、新建另一段临时会话、刷新或关闭页面，都不应当作临时聊天的保存方式；离开会话前请先导出。

## 更新与卸载

### 更新已有版本

- **手动安装：**用新版 ZIP 覆盖同一个 `st-chat-privacy` 文件夹，再强制刷新。不要额外安装第二个副本。
- **仓库安装：**在酒馆扩展管理中更新该扩展，再刷新。`auto_update` 未启用，需要手动检查更新。
- 确认扩展列表里的版本号变为 **0.3.6**。

覆盖安装只替换扩展文件，不需要删除酒馆的聊天数据。0.1.x、0.2.x、0.3.x 用户都可以覆盖更新；旧版创建的角色聊天仍可通过原生历史管理打开。

### 卸载

在酒馆扩展管理中禁用「聊天起始页」并刷新，或移走 `st-chat-privacy` 文件夹后刷新。扩展创建的角色／群聊记录仍由酒馆保留，界面恢复酒馆原来的显示方式。

## 常见问题

### 终端提示 `cannot find or open ...zip`

这表示命令指定的位置没有该 ZIP，通常是尚未下载，或文件名不一致。

先确认 ZIP 已保存到「下载」文件夹。浏览器重复下载时可能添加 ` (1)`，系统也可能自动解压 ZIP；请核对实际文件名。可以把 ZIP 从访达拖进终端，得到它的实际路径，再替换命令中 `unzip -o` 后面的路径。

### 覆盖安装了，页面还是旧版

先强制刷新，再核对扩展版本。确认解压到了**正在运行的那一份**酒馆目录，且没有多层文件夹或重复启用的扩展。如果使用多个酒馆副本，只更新其中一个目录不会影响另一个。

### 按日期没有反应

依次检查：本机日期是否正确、是否补齐四位、是否在三秒间隔内输入、光标是否还停在输入框、是否按着组合键。点击空白处，稍等后再输入一次。

若正文已经可见，数字不会触发入口；先按 Esc。旧版长按入口已停用，也不再需要 Option 键。

### 按 Esc 后像是聊天不见了

Esc 执行隐藏，不执行删除。角色／群聊可按当天日期打开历史列表，再选择当前记录；临时会话可按日期直接恢复。临时会话离开页面后的保留规则见上文。

### 临时聊天仍空白，或按钮仍重叠

先确认已更新到 0.3.6 并强制刷新。0.3.4 修复了临时会话被误当作加载页面的问题；0.3.5 修复按钮覆盖；0.3.6 将标签页恢复行为统一应用于角色、群聊、临时聊天和已打开的历史列表。

如果仍存在问题，反馈酒馆版本、扩展版本、使用的主题、复现步骤，以及不含聊天正文和密钥的截图。

### 切回标签页还是新建询问页

先核对扩展版本是否为 **0.3.6**，再强制刷新。0.3.5 只恢复临时聊天，角色聊天和历史列表需要更新到 0.3.6。

如果浏览器确实重新加载了页面，或你已经切换角色、按 Esc 手动隐藏，仍会回到默认隐藏状态。可按当天日期打开记录；临时聊天请遵循前面的导出规则。

### 首页记录不全

首页是原生「最近聊天」列表，显示数量受酒馆设置限制。进入对应角色／群聊的询问页，按日期打开聊天管理，查找更早的记录。

## 数据与隐私范围

- 聊天沿用酒馆原来的存储方式，本扩展不增加外部服务，也不上传聊天记录。
- 日期数字只在页面内存中短暂匹配，不保存到账号设置，也不发送给模型。
- 为衔接新建前后的聊天入口，扩展会在酒馆账号设置中保留少量角色／群聊及聊天文件名信息，不另存正文副本。
- 隐藏、展开和输入日期不会自动删除已保存的聊天。原生聊天管理中的删除操作仍由用户自行执行。
- 角色头像、侧边角色编辑面板、浏览器标题，以及其他扩展在主聊天区域外显示的弹窗，不属于遮挡范围。
- 日期规则公开且可预测，无法防止知道规则的人查看，也无法阻止别人直接读取电脑上的聊天文件。

## 兼容与验证

当前以官方 **SillyTavern 1.18.0，提交 `51ad27fb8`** 为适配基线。其他版本、主题和扩展组合尚需实际验证。触屏设备目前没有额外的日期输入控件。

开发检查使用该版本的原生 HTML、欢迎页和临时会话模板，以及选定的原生聊天函数，在模拟 DOM 和模拟后端中通过 **139 项检查**。覆盖日期入口、输入区域隔离、角色／群聊历史选择、新建保留、Esc、启动加载、临时聊天、草稿和标签页恢复等行为，包括反复切换、历史搜索保留、手动隐藏不被撤销及后台角色变化不显示其他聊天。

这些检查不等同于完整浏览器或真实酒馆实例测试；按钮在不同主题、缩放和窗口宽度下的最终布局仍需本机确认。
